## What it contains

An issue list has one row for each open point in the negotiation. Each row gives the clause reference and a short description of the issue. It sets out the counterparty's position and the party's own position and reasoning. It then gives the proposed resolution or fallback, the status of the point, and who must approve any concession.

## Who reads it

Negotiating counsel on both sides use the issue list to run calls and to track what has been agreed. The business owners read it to see which commercial points need their decision. The general counsel reads it to approve departures from the playbook.

## Standard of quality

A good issue list is complete: every change in the draft that has not been accepted appears in it. It is also accurate, so each row describes the current draft. Each row should make sense without the draft beside it. The list should be ordered by clause or by importance, with the points that need escalation clearly marked.

## Example structure

A typical issue list has columns for number, clause, issue, counterparty position, our position, proposed resolution, status and owner. For example, a row on the cap might read: clause 12.2; general cap; customer proposes three times annual fees; vendor proposes twelve months' fees; vendor to offer twenty-four months' fees in return for removing uncapped data protection liability; open; requires general counsel approval.
