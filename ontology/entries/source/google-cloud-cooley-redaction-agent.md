## Citation

Google Cloud Press Corner, "Cooley Collaborates With Google Cloud to Develop AI Agent for Complex Litigation", press release of 8 October 2026. Cooley also published the announcement on cooley.com. Google sells the Gemini Enterprise platform on which the agent runs, so this is vendor material.

## What it establishes

Cooley announced a collaboration with Google to build a Gemini Enterprise agent that helps lawyers review court filings for confidential material, and Cooley is the launch partner for it. The agent proposes redactions of personal data, technical information and other confidential material. The lawyers then decide. In the release's words, "Attorneys make all determinations about what should be redacted before the filing is submitted to the court." The release says the agent remains in development.
