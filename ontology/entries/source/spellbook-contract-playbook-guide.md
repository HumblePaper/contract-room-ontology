## Citation

Kurt Dunphy, "Legal Contract Playbook: How to Build and Enforce One with AI", Spellbook, last updated 26 September 2026. Spellbook sells AI contract review software that applies playbooks in Microsoft Word, so this is vendor marketing.

## What it establishes

The guide says a playbook records the position the team wants, the concessions it will accept, and the point past which a clause has to be escalated. It adds pre-approved clauses and suggested language for common terms. It describes the core structure as "a primary position for each key clause, plus a tier of fallbacks with defined limits." It also argues that a playbook has to change with experience. In its words, a great playbook "is enforced on every contract and evolves with each negotiation." The guide is on the list as a plain description of a playbook's parts. Its claims about AI enforcement are the vendor's own.
