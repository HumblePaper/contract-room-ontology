## Summary

This is a vendor post on Legora's own blog. A Skill is a set of plain-language instructions, saved as a Markdown file, that tells Legora's agent how a team does a given task. It can carry templates, past examples and examples of what the output should avoid. Legora says Skills differ from one-off prompts and fixed workflows, and that administrators can restrict sharing and remove a Skill from circulation. The post says the library holds more than 250 Skills across practice areas and jurisdictions.
